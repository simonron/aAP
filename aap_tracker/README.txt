Adapted Autonomic Profile (aAP) standalone web app

Open index.html in a modern browser.

Features:
- Patient Name and Participant Initials at the top of each day record.
- Each date is stored as a separate editable local record.
- Create PDF exports exactly one selected/current day per PDF file.
- Saved days can be reloaded, edited and exported again.
- Entry times remain editable and persist after reload.
- Expanding text areas for symptoms, activity, food/fluid and notes.
- Email PDF uses the device share sheet when file sharing is supported; otherwise it downloads that day's PDF and opens an email draft.

Data remains in this browser's local storage unless browser/site data is cleared.
